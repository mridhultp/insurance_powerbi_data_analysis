# Paramount Insurance – Power BI Dashboard

## Project Overview
Developed an end-to-end Insurance Analytics Dashboard using SQL Server, Power BI Desktop, and Power BI Service to monitor insurance premiums, coverage amounts, claims, policy status, and customer demographics.

## Tools & Technologies
- SQL Server Management Studio (SSMS)
- Microsoft Power BI Desktop
- Power BI Service
- Power BI Gateway
- DAX, Power Query
- Row-Level Security (RLS)

## Project Workflow

1. **Data Import:** Imported the InsuranceData Excel dataset into SQL Server Management Studio (SSMS).
2. **Data Connectivity:** Connected Power BI Desktop to the SQL Server database.
3. **Report Development:** Designed an interactive dashboard with KPIs, charts, slicers, and detailed transaction tables.
4. **Publishing:** Published the Power BI report to Power BI Service.
5. **Security Implementation:** Configured Row-Level Security (RLS) and tested and validated user-level data access.
6. **Dashboard Creation:** Pinned key KPIs and tables to create a dedicated Power BI Service dashboard.
7. **Gateway Configuration:** Established an On-premises Data Gateway connection between Power BI Service and the SQL Server database.
8. **Scheduled Refresh:** Configured daily scheduled data refresh at **7:00 PM IST**.

## Key Dashboard Insights
- Total Premium Amount
- Total Coverage Amount
- Total Claim Amount
- Premium by Policy Type
- Active vs. Inactive Policies
- Claims by Claim Status
- Claim Amount by Age Group
- Policy and Claim Analysis by Customer
